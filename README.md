# فاحص السيارة — نسخة Chrome (بدون تطبيق)

بيشتغل بـ **Chrome على أندرويد** (أو الكمبيوتر) وبيتصل **بقطعة ELM327 بلوتوث BLE** (مثل KUULAA / vLinker) مباشرة عبر Web Bluetooth. ما في داعي للابتوب ولا لتنزيل تطبيق.

- **الداشبورد:** عدادات، 12 قراءة، لمبات تحذير، ووضع HUD مقلوب للزجاج
- **الفحص الشامل:** الأكواد، الفحوصات الذاتية، Mode 06، صحة المحرك، الشحن، ووحدات VAG، مع علامة من 100 وتكلفة تقديرية
- **الرسمة:** صورة حقيقية لشكل السيارة، والمشاكل عليها بزوم
- **الأكواد:** قراءة، ومسح بعد التأكيد
- **قراءة فقط:** حارس UDS بيمنع الترميز والفلاش وكل أنواع الكتابة

## الاستعمال
1. افتح الرابط بـ Chrome على التلفون.
2. شغّل الإشعال، واكبس «اتصل بالقطعة (بلوتوث)»، واختار «OBD BLE».
3. «إضافة إلى الشاشة الرئيسية» بتخليه متل التطبيق.

## التطوير
- `npm test` (Node 20+)
- تشغيل محلي: `python -m http.server 8800` وبعدين افتح `http://localhost:8800` (Web Bluetooth بيشتغل على localhost أو HTTPS بس)

## المصادر والتراخيص
- منطق OBD منقول من مشروع obd-scanner (Python)، وانجرّب على سكودا كودياك 2023.
- الأكواد: [OBDex](https://github.com/foerbsnavi/OBDex) (CC0) و[dtc-database](https://github.com/Wal33D/dtc-database) (MIT)، والأكواد العربية من عملنا.
- صور السيارات من Wikimedia Commons بتراخيص حرة. التفاصيل بملف `cars/CREDITS.txt`.
